# Запуск проекта

## Windows

### Установка
1. Открой страницу проекта на GitHub.
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. Распакуй архив в удобную папку.

### Запуск

В той же папке выполни:

    python main.py

На Windows, если `python` не работает:

    py main.py

Мы в вас верим!

# Правила игры

## Поле

- Размер: **10 × 10**.
- Строки: **а, б, в, г, д, е, ж, з, и, к**.
- Столбцы: **1–10**.
- Координата: буква + цифра, например **а1**, **б6**, **к10**.

## Флот

- 4 однопалубных, 3 двухпалубных, 2 трёхпалубных, 1 четырёхпалубный.
- Расставляются случайно.
- Корабли не касаются друг друга: между ними минимум одна пустая клетка.

## Управление

- Ходит только игрок. Программа не стреляет сама.
- Ввод координаты через консоль: **а1**, **б6**, **к10**.

## Обозначения на поле

- `.` — пустая клетка
- `X` — попадание
- `*` — промах
